# 潮見帖（しおみちょう）— 全国の漁港・港湾の釣り情報マップ

全国 **3,925 か所**（漁港 2,931 / 港湾 994）を地図にマークし、港を選ぶと

- **今の時期に港内・堤防で釣れる魚**（地域別の季節カレンダー、釣り方・エサ・仕掛け付き）
- **天気・風向風速・波・水温・気圧**（現在＋週間）
- **タイドグラフ**（48時間の潮位、満潮/干潮、潮回り、月齢）
- **現在地からの直線距離と車ルート**（地図にルート表示、Google マップ連携）

をまとめて確認できる Web アプリです。**船釣りは対象外**（陸っぱり＝港内・堤防・岸壁）。

### Google マップを使う場合（任意）

未設定でも **国土地理院タイル + Leaflet** で動作します。Google マップに切り替えるには、
プロジェクト直下の `.env.preview`（ローカル開発なら `.env.local`）に次の2行を書きます。

```
GOOGLE_MAPS_API_KEY=（Google Cloud で発行したキー）
GOOGLE_MAPS_MAP_ID=        # 任意（空なら DEMO_MAP_ID）
```

- キーは**サーバー側で実行時に読み込む**ため、設定後に再ビルドは不要です（プレビューなら「更新」で再起動）。
- キーの指定を消すと、自動的に国土地理院タイルへ戻ります。
- Google Cloud 側で **Maps JavaScript API** の有効化と課金設定が必要です。
- キーはブラウザに配信されます。HTTP リファラー制限をかける場合は、公開先ドメインを登録してください。

## データの出どころ

| データ | 出典 | 備考 |
| --- | --- | --- |
| 漁港の位置・種別・施設延長 | 国土数値情報 **C09-06（漁港）** 国土交通省 | 添付の `data/source/C09-06_GML.8bdc55af.zip` |
| 港湾の位置・種別・施設延長 | 国土数値情報 **C02-14（港湾）** 国土交通省 | 添付の `data/source/C02-14_GML.401d042c.zip` |
| 地図タイル | 国土地理院（淡色 / 標準 / 写真） | 出典表示あり |
| 天気・風・波・水温 | [Open-Meteo](https://open-meteo.com/) | API キー不要 |
| 潮位 | Open-Meteo Marine（`sea_level_height_msl`） | 海洋モデルによる推算値 |
| 車ルート | OSRM（デモサーバー） | 失敗時は直線距離×1.3 の概算にフォールバック |
| 釣れる魚の季節 | 本アプリ独自データ `public/data/fish-species.json` | 下記「魚データの編集」参照 |

> 潮位は**推算値**です。釣行判断は必ず海上保安庁の潮汐表・気象庁の海上予報・現地の海況で確認してください。
> 漁港は漁業者の作業場所です。立入禁止区域・駐車禁止・漁協のルールを守って釣りをしてください。

## 港データの再生成

Shapefile（`.shp` / `.dbf`）から `public/data/ports.json` を作り直します。
**外部ライブラリ不要**（標準ライブラリのみで Shapefile を読みます）。

```bash
python3 scripts/build_ports.py
# -> public/data/ports.json  (約 750KB / 3,925件)
```

- 入力: `data/source/*.zip`（国土数値情報のダウンロードそのまま）
- 出力項目: `i`(ID) `k`(漁港f/港湾h) `n`(名称) `p`(都道府県) `pc`(都道府県コード)
  `r`(魚データ用の地域ID) `t`(種別名) `tc`(種別コード) `a`(管理者) `la`/`lo`(緯度経度)
  `code`(漁港/港湾コード) `ol`(外郭施設延長) `ml`(係留施設延長) `d`(指定年月日) `fy`(定期航路)
- 種別コード: 漁港 `1`〜`5`=第1〜5種 / 港湾 `11`国際戦略 `12`国際拠点 `13`重要 `14`地方 `15`その他

## 魚データの編集（季節カレンダー）

釣れる魚のデータは **`public/data/fish-species.json` 1ファイル**です。DB もビルドも不要で、
JSON を保存してブラウザを再読み込みすれば反映されます（`/api/fish` が毎回読み直します）。

### 種を追加する

1. `data/fish-species.template.json` をコピー
2. `public/data/fish-species.json` の `species` 配列の末尾に貼り付け
3. 値を書き換える

```jsonc
{
  "id": "kurodai",              // 重複しない半角英数（ケバブケース）
  "name": "クロダイ",
  "kana": "くろだい",            // 並び順に使用
  "aliases": ["チヌ", "黒鯛"],   // 検索・表示用の別名
  "group": "チヌ・スズキ",        // 下記 groups のいずれか
  "size": "25〜50cm",
  "methods": ["フカセ釣り", "ヘチ釣り"],
  "baits": ["オキアミ", "コーン"],
  "tackle": "磯竿4.5〜5.3m＋道糸2〜3号＋ハリス1.5号",
  "tip": "夜明け前後のヘチ際が狙い目。",
  "caution": "（任意）毒棘・採捕規制などの注意",
  "season": {                   // 地域ID: 釣れる月の配列（1〜12）
    "kanto": [5, 6, 7, 8, 9, 10, 11, 12],
    "kinki": [5, 6, 7, 8, 9, 10, 11, 12]
  },
  "peak": {                     // 最盛期（評価が +1、最大5）
    "kanto": [6, 7],
    "kinki": [6, 7]
  },
  "rating": 4                   // 基準の期待度 1〜5
}
```

- `season` に無い地域では、その港の一覧に**出てきません**（＝分布していない魚として扱う）
- 月の配列は年をまたいでもOK（例: `[11, 12, 1, 2, 3]`）
- 並び順は自動（評価 → 最盛期 → グループ → かな順）なので指定不要
- `groups` に新しいグループ名を足せば、その見出しでまとまります

### 地域区分（`regions`）

| 地域ID | 名称 | 都道府県 |
| --- | --- | --- |
| `hokkaido` | 北海道 | 北海道 |
| `tohoku` | 東北 | 青森・岩手・宮城・秋田・山形・福島 |
| `kanto` | 関東 | 茨城・栃木・群馬・埼玉・千葉・東京・神奈川 |
| `chubu` | 中部・北陸 | 新潟〜愛知（山梨・長野含む） |
| `kinki` | 近畿 | 三重〜和歌山 |
| `chushikoku` | 中国・四国 | 鳥取〜高知 |
| `kyushu` | 九州 | 福岡〜鹿児島 |
| `okinawa` | 沖縄 | 沖縄 |

地域を増やす場合は `regions` に追記し、`scripts/build_ports.py` の `REGION_OF_PREF` も
合わせて変更して港データを再生成してください。

### 種を削除する

`species` 配列から該当オブジェクトを丸ごと削除するだけです。

## Google スプレッドシートで魚データを管理する（推奨）

JSON を触らずに、スプレッドシートの行を追加・削除するだけで魚種を増減できます。

### 初期セットアップ（1回だけ）

1. `data/fish-sheet.csv` を Google スプレッドシートに**インポート**
   （スプレッドシートを新規作成 → ファイル → インポート → アップロード）
2. 共有設定を **「リンクを知っている全員（閲覧者）」** にする
3. URL `https://docs.google.com/spreadsheets/d/【ここがID】/edit` の ID をコピー
4. 環境変数 `FISH_SHEET_ID` に設定（Render の Environment / ローカルは `.env.preview`）
5. 再デプロイ → 以降はシートを編集して **5分待つ**だけで反映（デプロイ不要）

反映されているかは `https://<サイト>/api/fish` の `"source"` で確認できます。
`"sheet"` ならシート、`"json-fallback"` なら同梱JSONが使われています。

### 書き方

1行 = 1魚種です。列は `ID / 名前 / よみ / 別名 / グループ / サイズ / 釣り方 / エサ / 仕掛け / コツ / 注意 / 評価` と、
地域ごとの列（北海道・東北・関東・中部・北陸・近畿・中国四国・九州・沖縄）です。

地域のセルの書き方:

| 入力 | 意味 |
| --- | --- |
| `7,8,9` | 7〜9月が釣り期 |
| `5-9` | 5〜9月（範囲指定） |
| `7,8*,9` | 8月が**最盛期**（`*` を付けた月。評価が+1） |
| （空欄） | その地域では一覧に出ない |

- 行を**追加**すれば魚種が増え、行を**削除**すれば消えます
- 釣り方・エサは ` / ` 区切り、別名は `・` 区切り
- 評価は 1〜5（省略時は 3）

### 注意

- シートが読めない・列名が違う場合は、自動的に同梱の `public/data/fish-species.json` で動作します（画面は空になりません）
- 反映は 5 分キャッシュです。すぐ見たい場合は再デプロイしてください

## 画面の使い方

- 左の一覧: 港名・都道府県で検索、「漁港 / 港湾」切替、都道府県・種別で絞り込み、「近い順」ソート
- 地図: マーカーはズームに応じて自動でクラスタ化（数字は件数）。クリックで拡大
- 港を選ぶと右パネルに **釣りもの / 潮と天気 / アクセス / 施設情報**
- 月のマス目（1〜12）で「来月は何が釣れるか」も確認できます
- 右上「現在地」で距離とルートが有効になります（ブラウザの位置情報許可が必要）
- 地図右上で 淡色 / 標準 / 写真 を切替

## 構成

```
app/
  page.tsx                画面
  layout.tsx              メタデータ・CSS
  api/weather/route.ts    天気・波・潮位（Open-Meteo をまとめて返す）
  api/route/route.ts      車ルート（OSRM、失敗時フォールバック）
components/               UI（地図・一覧・詳細・タイドグラフ）
lib/                      計算ロジック（潮汐・風・距離・魚の季節・クラスタリング）
public/data/fish-species.json  魚の季節カレンダー（編集対象）
data/source/*.zip         国土数値情報の原本
public/data/ports.json    生成済みの港データ
scripts/build_ports.py    港データ生成スクリプト
```

### API

| エンドポイント | 内容 |
| --- | --- |
| `GET /api/weather?lat=&lon=` | 現在・48h・週間の天気/風/波/水温＋潮位・満干潮・潮回り（10分キャッシュ） |
| `GET /api/route?from=lat,lon&to=lat,lon` | 車の距離・所要時間・経路（GeoJSON） |

外部 API が `HTTPS_PROXY` 配下にある環境でも動くよう、プロキシ設定時は自動で経由します。

---

## 注意事項

- 天気・潮位はモデル推算値であり、実際の海況と異なる場合があります。
- 港湾・漁港の施設情報はデータ公開時点（漁港 2011年 / 港湾 2023年）のものです。
- 釣行時は各漁港・港湾の管理者、漁業協同組合、自治体の指示に従ってください。
